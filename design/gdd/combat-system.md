# 战斗系统 (Combat System)

## 1. Overview

回合制策略战斗系统。双方各派最多 3 名武将上阵，在 8 回合内决出胜负。武将按速度顺序行动，使用普攻和战法削减对方生命值。8 回合结束时若双方仍有存活武将，判为平局。

战斗流程：战前准备（组队、配点）→ 战斗开始（指挥/被动触发）→ 回合循环（按速度顺序行动）→ 结算（胜负判定、奖励发放）。

## 2. Player Fantasy

- **运筹帷幄**：通过武将搭配、属性配点、战法组合构建制胜策略
- **以弱胜强**：合理的属性克制和战法搭配可以击败面板更强的对手
- **瞬息万变**：战法发动概率带来不确定性，战斗不完全是数值比拼
- **三国代入感**：每位武将的属性等级（S/A/B/C/D）反映历史形象，自带战法体现人物特色

## 3. Detailed Rules

### 3.1 上阵规则
- 每队最多上阵 3 名武将
- 战斗开始前确定阵容，战斗中不可更换

### 3.2 行动顺序
- 战斗开始时，先按速度顺序触发双方指挥战法和被动战法效果
- 之后每回合按速度从高到低依次行动
- 速度相同的情况下，进攻方优先

### 3.3 武将属性
每名武将有五项基础属性：

| 属性 | 说明 |
|------|------|
| 武力 | 影响物理伤害输出 |
| 智力 | 影响策略伤害输出 |
| 防御(统帅) | 减少受到的伤害 |
| 速度 | 决定行动顺序 |
| 生命 | 固定为 10000 |

属性等级与数值对照：

| 等级 | 武力/智力 | 统帅 | 速度 |
|------|-----------|------|------|
| S | 200 | 90 | 100 |
| A | 180 | 80 | 90 |
| B | 160 | 70 | 80 |
| C | 140 | 60 | 70 |
| D | 100 | 50 | 60 |

每名武将有 50 点自由属性点，玩家可任意分配到四项属性上（武力/智力/统帅/速度）。

### 3.4 战法系统
每名武将：
- 1 个自带战法（不可更换）
- 最多携带 2 个额外战法

战法类型：

| 类型 | 触发时机 | 说明 |
|------|----------|------|
| 主动战法 | 武将行动时 | 有发动率，按概率判定 |
| 追击战法 | 普攻后 | 有发动率，按概率判定 |
| 指挥战法 | 按具体描述 | 战斗开始或满足条件时触发 |
| 被动战法 | 按具体描述 | 持续生效或满足条件时触发 |

### 3.5 普攻
- 造成 100% 武力伤害
- 不受发动率影响，每回合必定执行（除非被控制）

### 3.6 控制与状态效果

| 效果 | 描述 |
|------|------|
| 技穷 | 无法释放主动战法 |
| 缴械 | 无法释放普攻 |
| 震慑 | 无法行动 |
| 规避 | 闪避受到的伤害 |

增益效果：

| 效果 | 描述 |
|------|------|
| 破甲 | 无视目标统帅 |
| 破阵 | 无视目标减伤 |
| 会心 | 造成伤害必定暴击 |
| 连击 | 每回合普攻两次 |
| 清醒 | 免疫控制效果 |
| 穿透 | 无视护盾 |

减益效果：

| 效果 | 描述 |
|------|------|
| 洪水 | 统帅 -10，上限 3 层 |
| 畏惧 | 受到伤害提升 10% |

## 4. Formulas

### 4.1 武力伤害公式

```
伤害 = 攻击倍率 × (攻击者武力 - 被攻击者统帅) × (1 + 增伤% - 减伤%) × (1 + 受到伤害提升% - 受到伤害降低%)
```

### 4.2 智力伤害公式

```
伤害 = 攻击倍率 × (攻击者智力 - 0.6 × 被攻击者统帅 - 0.4 × 被攻击者智力) × (1 + 增伤% - 减伤%) × (1 + 受到伤害提升% - 受到伤害降低%)
```

### 4.3 破防规则
若 `攻击者武力 - 被攻击者统帅 ≤ 0`（武力）或 `攻击者智力 - 0.6×被攻击者统帅 - 0.4×被攻击者智力 ≤ 0`（智力），则伤害固定为 1。

### 4.4 特殊伤害类型

| 类型 | 规则 |
|------|------|
| 持续伤害 (DoT) | 只与施加者攻击力和伤害倍率有关，不可暴击 |
| 暴击伤害 | 初始暴击伤害 = 原伤害 × 150% |
| 附加伤害 | 固定数值，不参与伤害公式计算 |

### 4.5 吸血效果
- 倒戈：造成武力伤害时，回复造成伤害一定比例的生命
- 攻心：造成智力伤害时，回复造成伤害一定比例的生命

## 5. Edge Cases

- **双方同时死亡**（第 8 回合最后一击同归于尽）：判为平局
- **速度完全相同**：进攻方优先行动
- **破防伤害为 1**：即使攻击方有增伤也要先判定破防，未破防则固定 1
- **多次控制叠加**：同类型控制效果不叠加，取剩余回合数最多者
- **洪水叠加**：上限 3 层 (-30 统帅)，超过 3 层不再叠加
- **属性配点后属性为负数**：不允许，分配前校验可用点数
- **暴击 + 会心叠加**：会心下必定暴击，暴击伤害倍率正常应用
- **规避 vs 必中**：必中效果优先于规避（如有命中属性）
- **吸血致死**：吸血回复先于伤害结算导致的死亡判定

## 6. Dependencies

| 依赖系统 | 关系 |
|----------|------|
| 武将系统 (`generals-system`) | 武将数据（属性、自带战法） |
| 战法系统 (`skills-system`) | 战法定义、效果、发动率 |
| 组队系统 (`team-builder-system`) | 战前阵容选择和属性配点 |
| 战斗结果系统 (`battle-result-system`) | 战斗结算后传递胜负和奖励数据 |
| 抽卡系统 (`gacha-system`) | 武将获取来源 |

## 7. Tuning Knobs

| 参数 | 当前值 | 可调范围 | 影响 |
|------|--------|----------|------|
| 最大上阵人数 | 3 | 1-5 | 战斗复杂度 |
| 最大回合数 | 8 | 5-20 | 战斗时长 |
| 生命值上限 | 10000 | 5000-50000 | 战斗节奏 |
| 自由属性点 | 50 | 0-200 | 养成深度 |
| 暴击伤害倍率 | 150% | 120%-200% | 暴击收益 |
| 武力/智力 S 级值 | 200 | 150-300 | 属性天花板 |
| 统帅 S 级值 | 90 | 60-150 | 防御天花板 |
| 智力伤害统帅系数 | 0.6 | 0.3-0.8 | 智力 vs 物理平衡 |
| 智力伤害智力系数 | 0.4 | 0.2-0.6 | 智力对抗权重 |
| 洪水每层减统帅 | 10 | 5-20 | 减益强度 |
| 畏惧增伤 | 10% | 5%-20% | 增伤强度 |

## 8. Acceptance Criteria

- [ ] AC-01：3v3 战斗能完整进行 8 回合并产生胜负/平局结果
- [ ] AC-02：武将按速度顺序行动，速度高者先动
- [ ] AC-03：武力伤害公式计算结果正确（手动验算 5 组不同属性组合）
- [ ] AC-04：智力伤害公式计算结果正确（手动验算 5 组不同属性组合）
- [ ] AC-05：未破防时伤害固定为 1
- [ ] AC-06：暴击伤害 = 原伤害 × 150%
- [ ] AC-07：指挥战法和被动战法在战斗开始时正确触发
- [ ] AC-08：主动战法按发动率概率触发（1000 次测试，偏差 ≤ 3%）
- [ ] AC-09：控制效果（技穷/缴械/震慑）正确限制对应行动
- [ ] AC-10：规避效果正确闪避伤害
- [ ] AC-11：持续伤害不可暴击
- [ ] AC-12：属性配点后武将属性值正确更新
- [ ] AC-13：8 回合结束后双方均有存活武将 → 平局
- [ ] AC-14：一方全部阵亡 → 立即结束，不等第 8 回合
